- `HwpxPackageInspector.cs:119-121` 은 섹션마다 첫 `pageBorderFill` 참조 하나만 확인한다. 각 섹션에 배경 이미지가 실제로 연결됐는지, 즉 "빈 페이지가 아님"은 검사하지 않는다. P1-1 처럼 렌더 내용이 비어도 PASS 가 나오는 이유 중 하나다.

## 8. 권장 작업 순서 (작은 단위)

1. **(P1-1 테스트 먼저)** 오프셋이 있는 비대칭 CropBox(예: `100 150 200 200`) fixture 와 **픽셀 내용** 단언을 추가해 실패를 확인한다. 회전 0/90/180/270 을 함께 다룬다.
2. **(P1-1 수정)** `PdfiumPageRenderer` 에서 원본 CropBox 와 같은 크롭은 `Bounds` 로 넘기지 않게 한다. 사용자 지정 크롭이 필요하면 CropBox 기준·좌상단 원점 좌표로 변환해 넘긴다. 1번 테스트와 기존 106개 테스트로 확인한다.
3. 검사기 또는 변환 후 단계에 "섹션마다 배경 리소스 연결" 검사를 추가한다(P3-6).
4. 기록 삭제를 인덱스 대신 안정 키(Timestamp+OutputPath 또는 새 Id 필드)로 바꾸고 회귀 테스트를 추가한다(P2-1).
5. `Convert` 에서 검증 실패 시 `RecordOutcome` 을 건너뛰거나 `_activeSnapshot` 을 초기화한다. 실패 기록 경로에는 실제 출력 이름을 쓴다(P2-2).
6. `App` 에 `DispatcherUnhandledException` 처리기를 두고 `ExportReport`/`ExportDiagnostics`/`OpenResults` 에 try/catch 를 추가한다(P2-3).
7. `AddFilesAsync` 에서 파일별로 예외를 처리하고, 암호화 PDF 전용 메시지를 둔다(P2-4).
8. 샘플 생성 도구는 기본 출력 경로를 별도 폴더로 바꾸거나, 기존 파일이 있으면 중단하게 한다(P2-6).
9. 원본 해시는 작업당 한 번만 계산해 캐시하고, Visual Fidelity 분석 때 글자 추출을 생략한다(P2-5).
10. `verify-license-assets.ps1` 의 PS 7 요구를 CLAUDE.md·AGENTS.md 검증 명령 목록에 적거나, 스크립트를 PS 5.1 호환으로 고친다(P3-1). 그 뒤 `pwsh` 환경에서 다시 실행한다.
11. 핸드오프를 실제 상태(HEAD `ca66318`, `docs/recovery/` 추적됨, SDK 8 PASS, 중복 문단 정리)로 갱신하고 CLAUDE.md 의 `cd7ced4`·`docs/recovery` 문구를 고친다.
12. 정리: 루트 `run.err`/`run.out`/`section18.xml` 처리, UI·메타 문구에서 "HWP" 제거, 마커 없는 렌더 폴더 정리 정책 정비(P3-2~P3-5).
13. 한컴오피스 2024 로 샘플 #23 수동 검증(파일 수정 금지).
